# legal

Privacy policies and support pages for apps published under [bernouli-ui](https://github.com/bernouli-ui).

Hosted via GitHub Pages at https://bernouli-ui.github.io/legal/.

## Apps

- **Fillr** — [privacy](https://bernouli-ui.github.io/legal/fillr/privacy.html) · [support](https://bernouli-ui.github.io/legal/fillr/support.html)

## Adding a new app

1. Create a new folder, e.g. `myapp/`.
2. Add `privacy.html` and `support.html` (copy from `fillr/` and edit).
3. Add a card to `index.html`.
4. Commit and push — GitHub Pages will redeploy automatically.

## Notes

- All pages share `_shared.css` for consistent styling.
- The site supports light and dark mode via `prefers-color-scheme`.
- Pages are pure static HTML — no build step.
