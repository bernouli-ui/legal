## Adding a new app

1. Create a new folder, e.g. `myapp/`.
2. Add `privacy.html` and `support.html` (copy from `conch/` and edit).
3. Add a card to `index.html`.
4. Commit and push — GitHub Pages will redeploy automatically.

## Notes

- All pages share `_shared.css` for consistent styling.
- The site supports light and dark mode via `prefers-color-scheme`.
- Pages are pure static HTML — no build step.
