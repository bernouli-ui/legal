Need help with Fillr? You're in the right place.

About Fillr

Fillr is a head-to-head iPhone game played over a local Wi-Fi network. Two phones running Fillr on the same network can find each other automatically and play together — no accounts, no servers, no internet required.

How multiplayer works

  • Both phones must be on the same Wi-Fi network.
  • One phone taps "Host a game"; the other taps "Join a game."
  • The connection is direct and peer-to-peer. Nothing is sent through the internet.

Troubleshooting

  • The other phone isn't showing up. Make sure both phones are on the same Wi-Fi network, and that Fillr has Local Network permission (Settings › Fillr › Local Network).
  • Local Network permission was denied. Enable it in Settings › Privacy & Security › Local Network › Fillr.
  • The connection drops mid-game. This usually means one phone left the Wi-Fi network or moved out of range. Reconnect and start a new match.
