Glowy Support

Need help with Glowy? You're in the right place.

About Glowy

Glowy is a collection of six original couch-multiplayer iPhone games: Filler, Spotter, Memory, Push Card, Mojong, and Chain. Two phones running Glowy on the same Wi-Fi network can find each other automatically and play together — no accounts, no servers, no internet required. Every game also includes a solo vs-AI mode.

How multiplayer works

  • Both phones must be on the same Wi-Fi network.
  • One phone taps "Host a game"; the other taps "Join a game."
  • The connection is direct and peer-to-peer. Nothing is sent through the internet.

Troubleshooting

  • The other phone isn't showing up. Make sure both phones are on the same Wi-Fi network, and that Glowy has Local Network permission (Settings › Glowy › Local Network).
  • Local Network permission was denied. Enable it in Settings › Privacy & Security › Local Network › Glowy.
  • The connection drops mid-game. This usually means one phone left the Wi-Fi network or moved out of range. Reconnect and start a new match.
  • The two phones see different tile patterns. Glowy syncs your chosen theme over the wire when a match starts; if it doesn't update, make sure both phones are running the same Glowy version (App Store › Glowy › Update).

Reporting a bug

If you run into something that isn't working, please email me with:

  • Which game you were playing (Filler, Spotter, Memory, Push Card, Mojong, or Chain)
  • Whether you were playing solo vs the AI or in multiplayer
  • What you did and what you saw happen
  • Your iPhone model and iOS version (Settings › General › About)
  • Your Glowy version (App Store › Glowy)
